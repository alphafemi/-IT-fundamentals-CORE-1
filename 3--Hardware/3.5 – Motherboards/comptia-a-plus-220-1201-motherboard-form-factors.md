## Overview

Motherboard form factors define the **physical size**, **component layout**, **mounting hole positions**, and **power connector standards** for a motherboard. Choosing the right form factor depends on the use case, case size, and expansion requirements.

For the A+ exam, you need to know three form factors: **ATX**, **Micro-ATX**, and **Mini-ITX**.

**Key considerations when selecting a motherboard form factor:**
- Physical size / case compatibility
- Number of expansion slots needed
- Number of memory slots needed
- Power connector type
- Airflow and cooling requirements

---

## ATX — Advanced Technology Extended

- **Introduced:** 1995; current standard still traces back to this original design
- **Size:** Largest of the three exam-relevant form factors
- **Power connector:** Originally 20-pin; modern ATX uses **24-pin** main power connector
- **Expansion slots:** Most — typically 4–7 PCIe/PCI slots
- **Memory slots:** Most — typically 4 slots (some high-end boards have 8)
- **Use case:** Full-size desktop computers, workstations, gaming rigs, video editing systems

ATX provides the most flexibility for expansion cards, memory, and cooling options. It requires a full-size ATX tower or mid-tower case.

---

## Micro-ATX

- **Size:** Smaller than ATX; similar layout
- **Mounting points:** **Same mounting hole positions as ATX** — fits in ATX cases
- **Power connector:** Same 24-pin power connector as ATX
- **Expansion slots:** Fewer — typically 1–4 slots
- **Memory slots:** Fewer — typically 2–4 slots
- **Use case:** Compact desktops, budget builds, small office computers

Micro-ATX follows the same standards as ATX and is backward compatible with ATX cases. The trade-off for the smaller size is fewer expansion and memory slots.

---

## Mini-ITX

- **Size:** Smallest of the three — very compact
- **Mounting points:** **Same mounting hole positions as ATX** — fits in ATX cases
- **Power connector:** Same standard ATX power connectors
- **Expansion slots:** Very few — typically 1 slot
- **Memory slots:** Typically 2 slots
- **Use case:** HTPCs (Home Theater PCs), streaming media centers, single-purpose appliances, embedded systems, very tight spaces

Mini-ITX's shared mounting point standard means it can be installed in an ATX case with extra room, or in purpose-built compact cases.

---

## Form Factor Comparison

| Feature | ATX | Micro-ATX | Mini-ITX |
|---|---|---|---|
| Relative size | Largest | Medium | Smallest |
| Introduced | 1995 | Later | Later |
| Main power | 24-pin | 24-pin | 24-pin |
| Expansion slots | Most (4–7) | Fewer (1–4) | Very few (1) |
| Memory slots | Most (4–8) | Fewer (2–4) | Least (2) |
| ATX case compatible | Yes (native) | Yes (same mount points) | Yes (same mount points) |
| Best for | Workstations, gaming, full builds | Compact desktops, budget builds | Media centers, single-purpose PCs |

> **Key exam fact:** All three form factors share the same mounting hole positions, so a Mini-ITX or Micro-ATX board can be installed in a full ATX case.

## Key Takeaways

| Topic | Key Fact |
|---|---|
| ATX | Largest; most expansion/memory slots; 24-pin power; full-size desktop use |
| ATX power history | Originally 20-pin; modern ATX = 24-pin |
| Micro-ATX | Smaller than ATX; same mounting points and power; fewer slots |
| Mini-ITX | Smallest; 1 expansion slot; 2 memory slots; media center / compact use |
| Shared mount points | All three use the same screw hole positions — all fit in ATX cases |
| Form factor choice | More expansion needed → ATX; compact/low-power → Micro-ATX or Mini-ITX |
