# CompTIA A+ 220-1201 — Network Cables & Cabling Standards

> **Exam Domain Reference** | Core 1 (220-1201) — Networking (Domain 2)  
> Topics: Twisted pair, cable categories, UTP/STP shielding codes, coaxial, direct burial, plenum-rated cable

---


## Overview

All network communication — including wireless — ultimately depends on physical cabling at some point. Access points, switches, routers, and servers all connect via cable. Selecting the correct cable type, category, and rating for the environment is critical for reliable, code-compliant network installations.

---

## Twisted Pair Cable

Twisted pair is the most common cable type for wired Ethernet networks. Each cable contains **four pairs of copper wires**, with each pair twisted together.

### How Twisting Reduces Interference

Each pair carries **equal and opposite signals** (e.g., Transmit+ and Transmit−). When interference hits the cable, it affects both wires in the pair equally. The receiving device compares the two signals and cancels out the interference — keeping only the real data signal. This is called **differential signaling**.

**Additional detail:** Each pair is twisted at a **different rate**. This means interference affects each pair slightly differently, making it even easier for the receiver to distinguish noise from signal.

### Cable Categories & Speed Standards

The IEEE 802.3 standard defines the **minimum cable category** required for each Ethernet speed. The category is printed on the outside of the cable jacket.

| Category | Ethernet Standard | Max Speed | Max Distance | Notes |
|---|---|---|---|---|
| **Cat 5** | 1000BASE-T | 1 Gbps | 100 m | Deprecated — no longer sold new |
| **Cat 5e** | 1000BASE-T | 1 Gbps | 100 m | Enhanced Cat 5; current minimum |
| **Cat 6** | 10GBASE-T | 10 Gbps | 55 m (UTP) / 100 m (STP) | Common for 10G installs |
| **Cat 6A** | 10GBASE-T | 10 Gbps | 100 m | Augmented; full 100 m at 10G |
| **Cat 7** | 10GBASE-T+ | 10 Gbps+ | 100 m | S/FTP shielding; per-pair foil |

> **Exam Tip:** Cat 5 is deprecated — if you're buying new cable, it's Cat 5e or higher. Cat 6 unshielded only reaches 55 m at 10G; Cat 6A reaches the full 100 m.

**Key principle:** Always use the minimum cable category specified by the IEEE standard for the Ethernet type you are running. Going above the minimum is fine — going below is not supported.

## Shielding Types

Twisted pair cables are available in **unshielded (UTP)** and **shielded (STP)** variants.

| Type | Description | Use Case |
|---|---|---|
| **UTP** — Unshielded Twisted Pair | No shielding on pairs or overall | Standard office/home environments |
| **STP** — Shielded Twisted Pair | Shielding around some or all pairs | High-interference environments; longer runs |

### Shielding Notation

The shielding type is printed on the cable jacket using a standardized abbreviation:

```
[Overall Shield] / [Pair Shield] TP
```

**Shield abbreviations:**

| Code | Meaning |
|---|---|
| **U** | Unshielded |
| **S** | Braided shield |
| **F** | Foil shield |

**Reading the code:**

| Cable Code | Overall Shield | Pair Shield | Example Use |
|---|---|---|---|
| **U/UTP** | None | None | Standard Cat 5e/6 office cable |
| **F/UTP** | Foil | None | Light shielding; Cat 6 |
| **S/FTP** | Braided | Foil on each pair | Cat 7; maximum shielding |
| **U/FTP** | None | Foil on each pair | Individual pair protection |

> **Example:** A cable labeled **S/FTP** has a braided shield around all four pairs **plus** individual foil shielding around each pair — maximum protection against interference.

## Coaxial Cable

Coaxial cable has a single central copper conductor surrounded by insulation, a metallic shield, and an outer jacket. "Coaxial" refers to the inner conductor and outer shield sharing a common axis.

**Common networking use:**
- **Cable modem / DOCSIS** — high-speed internet over cable TV infrastructure
- **Digital cable television**

The outer shield protects the signal on the inner conductor from interference — similar in principle to the shielding on STP, but in a single-conductor form.

## Direct Burial Cable

Direct burial cable is designed to be **installed in the ground** between buildings — without requiring a protective conduit.

**Construction features:**

| Feature | Purpose |
|---|---|
| Waterproof outer jacket | Protects against moisture in soil |
| Waterproof gel inside | Prevents water wicking along the wires |
| Shielded twisted pair (STP) | Protects against interference; provides grounding path |
| **Drain wire** | A bare copper wire running the full length; used for electrical grounding |

> **"Drain wire"** = the grounding conductor inside a direct burial or shielded cable.

**When to use:** Connecting buildings across a campus or parking lot where overhead runs are impractical or undesirable.

## Plenum-Rated Cable

### What Is Plenum Space?

In many commercial buildings, **plenum space** is the open area above a drop ceiling used for air return. Because this space is open and connected throughout the building, fire, smoke, and toxic fumes can travel freely through it.

```
Drop ceiling tiles
─────────────────────────────────
        PLENUM SPACE
  (cables, ductwork, air return)
─────────────────────────────────
Structural floor/ceiling above
```

### Why Standard Cable Is Dangerous in Plenum Space

Standard Ethernet cable uses a **PVC (PolyVinyl Chloride)** jacket. When PVC burns, it releases **toxic fumes** that can rapidly spread through plenum air spaces and endanger building occupants.

### Plenum-Rated Cable

Plenum-rated cable uses a **fire-resistant, low-smoke jacket** material:

| Material | Abbreviation | Notes |
|---|---|---|
| **Fluorinated Ethylene Polymer** | FEP | Fire-rated; low smoke; most common plenum jacket |
| **Low-smoke PVC** | Low-smoke PVC | Alternative plenum-rated material |

**Trade-off:** Plenum-rated cable is **less flexible** than standard PVC cable and may be slightly more difficult to route and terminate.

**Rule:** If cable runs above a drop ceiling in a commercial environment with plenum air return, **plenum-rated cable is required** — both by code and for safety.

| Location | Required Cable Type |
|---|---|
| Standard walls / conduit | PVC jacket (standard) |
| Above drop ceiling (plenum) | FEP or low-smoke PVC (plenum-rated) |
| Underground between buildings | Direct burial STP |

## Cable Type Summary

| Cable Type | Medium | Common Use | Key Feature |
|---|---|---|---|
| **UTP** | Copper twisted pair | Standard office Ethernet | No shielding; flexible; inexpensive |
| **STP** | Copper twisted pair | High-interference environments | Shielded pairs; longer 10G runs |
| **Coaxial** | Copper (coax) | Cable modem, DOCSIS | Central conductor + outer shield |
| **Direct burial** | Copper STP | Underground between buildings | Waterproof; gel-filled; drain wire |
| **Plenum-rated** | Copper (any type) | Above drop ceilings | FEP or low-smoke PVC jacket |
