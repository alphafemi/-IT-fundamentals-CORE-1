## Print Head Cleaning

Inkjet print heads clog easily with dried or excess ink — the most common maintenance task.

**Automated cleaning:**
- Most inkjet printers run an **automatic cleaning cycle every 24 hours**
- Wipes excess/dried ink from the print head
- Some cleaning cycles use a small amount of ink

**Manual cleaning:**
- Can be initiated from the printer's software or settings menu
- Useful if the printer is used heavily (more frequent cleaning needed)
- Some printers allow physically removing the print head or cartridge for **careful manual cleaning**

**Symptom of dirty print head:** Colored streaks across the printed page.

> **Always check the manufacturer's documentation** for the recommended cleaning method — procedures vary significantly between printer brands.

## Cartridge Replacement

**Common CMYK cartridge configurations:**

| Configuration | Description |
|---|---|
| **Combined color + separate black** | Cyan, magenta, and yellow in one cartridge; black is separate |
| **All separate** | Individual cartridges for each of C, M, Y, K |
| **All-in-one** | All four colors in a single cartridge |

**Replacement process:**
1. Open the printer cover / cartridge access door
2. Pop out the empty cartridge
3. Insert the new cartridge — it clicks into place
4. Allow the printer to run its post-installation calibration

**Recycling:** Ink cartridges are primarily plastic — most manufacturers provide recycling programs.

## Calibration

Calibration ensures all ink colors align precisely on the printed page — misalignment causes color fringing or blurry output.

**When to calibrate:**
- After every **new cartridge installation** (usually automatic)
- Any time output quality seems off — colors not lining up properly

**How it works:**
1. Printer prints a **calibration test page** with color blocks and alignment marks
2. User selects the best-aligned pattern (or the printer reads it automatically)
3. Settings are adjusted to align the print heads

**Result:** Crisp, properly aligned color output across all CMYK channels.

## Clearing Paper Jams

Paper occasionally catches on the internal mechanisms of an inkjet printer.

**Process:**
1. Open the printer cover to access the paper path
2. **Carefully pull the jammed paper out** — slow and steady to avoid tearing
3. Check that **no pieces of paper remain** inside the paper path — even small fragments can cause repeat jams
4. Close the cover and resume printing

**Tips:**
- Some printers have a simple, accessible paper path; others are more complex — consult the manual if needed
- Never force paper out — this can damage feed rollers or the print carriage
- Always pull in the **direction of paper travel** when possible
