## How Inkjet Printers Work

An inkjet printer (also called an **ink dispersion printer**) creates output by propelling tiny drops of ink from a cartridge onto paper.

**Advantages:**
- Inexpensive hardware
- Quiet operation
- High-resolution output — ideal for graphics and photographs
- Black and white and full color output

**Disadvantages:**
- Ink is **expensive** and **proprietary** — specific to each manufacturer
- Ink **fades over time** — output appearance degrades
- Ink **clogs easily** — ongoing maintenance challenge; each manufacturer addresses it differently

---

## Ink Cartridges & Colors (CMYK)

Inkjet printers use **four colors** to create the full range of output:

| Letter | Color | Notes |
|---|---|---|
| **C** | Cyan | |
| **M** | Magenta | |
| **Y** | Yellow | |
| **K** | Key (Black) | "K" = Key to avoid confusion with Blue in RGB |

**Cartridge configurations:**
- **Individual cartridges** — one per color; most common; replace only the color that runs out
- **Combined cartridge** — all colors in one cartridge; cheaper upfront, but replacing one empty color wastes the remaining ink

---

## Print Heads

The print head is the component that actually deposits ink drops onto the paper.

**Two designs:**

| Design | Description |
|---|---|
| **Integrated** | Print head is built into the ink cartridge — replacing the cartridge gives a new print head |
| **Separate** | Print head is a permanent fixture in the printer; only the ink cartridge is replaced |

**Integrated print head advantage:** Automatic print head renewal with each cartridge replacement — eliminates most print head maintenance.

**Handling:** Print heads are extremely delicate — use great care when cleaning or handling to avoid damage.

---

## Feed Rollers

Feed rollers pull paper into the printer and advance it past the print heads.

**Location:** Typically at the front of the paper path, above the paper tray.

**Common issue:** Rollers accumulate dirt and ink over time → paper feed failures (paper not pulling in properly, skewed printing, jams).

**Fix:** Clean the feed rollers. This resolves most paper feed issues.

---

## Carriage & Belt

The **print carriage** holds the ink cartridge(s) and print head and moves horizontally across the page during printing.

The **carriage belt** drives the back-and-forth movement of the carriage across the paper.

**Common issues:**
- Worn or loose belt → inconsistent spacing or misaligned output
- Carriage obstruction → printer stops mid-print or displays an error

---

## Calibration

After installing new ink cartridges (especially if the print head is separate from the cartridge), the printer may need to be **calibrated** to align the print heads.

**Why it's needed:** Slight mechanical differences between cartridges can cause color misalignment or banding.

**Process:**
- The printer prints a **calibration/alignment page** with test patterns
- The user selects the best-aligned pattern (or the printer reads it automatically with a sensor)
- Settings are adjusted to correct alignment

## Inkjet vs. Laser Comparison

| Feature | Inkjet | Laser |
|---|---|---|
| Print technology | Ink drops on paper | Toner fused with heat |
| Color output | Yes (CMYK) | Yes (CMYK, higher-end models) |
| Photo quality | Excellent | Good |
| Speed | Slower | Faster |
| Noise | Quiet | Moderate |
| Hardware cost | Low | Higher |
| Per-page cost | High (ink is expensive) | Lower (toner is efficient) |
| Ink/toner fading | Yes (fades over time) | More durable |
| Clogging | Yes — ongoing issue | No |
| Complexity | Simpler | More complex |
